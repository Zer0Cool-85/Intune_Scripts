# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-08-12

### Added

- Single-file JSON configuration.
- Self-contained install, uninstall, requirement, and detection script generation.
- Optional Microsoft Win32 Content Prep Tool integration.
- Explicit 64-bit uninstall-registry handling.
- File and scheduled-task application-presence markers.
- Dependency-free repository validation tests.
- GitHub Actions validation workflow.
- Intune configuration and troubleshooting documentation.
